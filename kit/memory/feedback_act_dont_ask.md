---
name: feedback-act-dont-ask
description: Execute end to end; pick sensible defaults instead of bouncing small decisions or steps back to the user
metadata:
  type: feedback
---
When the user asks for something to be done, do every step that is technically possible yourself. Escalate only true blockers: admin/UAC prompts, sign-ins, payments, hardware.

**How to apply:** default to act, not ask. Try another method before reporting "you need to do X manually". Batch any unavoidable sign-in or approval into one ask. Destructive or outward-facing actions (delete, publish, send) still get confirmation first.
