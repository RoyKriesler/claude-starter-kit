  type: feedback

Use the click-to-pick `AskUserQuestion` tool for real choices, up to 4 questions with up to 4 options each.

**How to apply:** only for genuine forward-looking choices; status updates stay plain text. Irreversible actions (delete, force-push) keep an explicit written confirmation. When a reasonable default exists, prefer acting on it — see [[feedback-act-dont-ask]].
