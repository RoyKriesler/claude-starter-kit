---
name: feedback-no-fabrication
description: In CVs, bios, cover letters and any document about a real person, use only facts the user gave; never invent skills, tools or interests to fill space
metadata:
  type: feedback
---
Never add skills, tools, certifications, hobbies or claims that are not in the source material, even to fill an empty page.

**Why:** invented facts in a CV are lies the user would have to defend in an interview.

**How to apply:** fill space by rephrasing and expanding real content, layout, whitespace. If the source is too thin, ask the user what to add. Empty space stays empty otherwise.
